# BYDAT — Портфолио веб-разработчика

Стильное, лаконичное веб-портфолио в темной теме для демонстрации клиентских сайтов и версток.
Все проекты полностью автономны, не требуют сборщиков и серверов (Zero-Config), готовы для мгновенного просмотра локально и через **GitHub Pages**.

**Живая ссылка**: [https://bydat.github.io/portfolio_new/](https://bydat.github.io/portfolio_new/)

---

## 📁 Структура проектов

Портфолио включает отобранные проекты в 3 категориях:

### 1. Салоны & Красота
- **SENSE LAB** (`projects/scent/`) — Концептуальное пространство нишевой парфюмерии и арома-бара с онлайн-конструктором ароматов.

### 2. Авто & Детейлинг
- **Luxury Detailing** (`projects/detaling/`) — Премиальный центр детейлинга, защиты авто и интерактивным калькулятором услуг.

### 3. Мебель & Производство
- **MODUS STUDIO** (`projects/modus/`) — Интернет-магазин и конфигуратор авторской мебели на заказ.

---

## 🚀 Локальный запуск

1. Дважды кликните по файлу **`index.html`** в проводнике — портфолио откроется в браузере.
2. Проекты работают по относительным путям без необходимости поднимать сервер.

---

## 🌐 Публикация на GitHub Pages

1. Репозиторий: `https://github.com/bydat/portfolio_new`
2. Перейдите во вкладку **Settings → Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`
   - Нажмите **Save**.
4. Сайт будет доступен по адресу:
   **`https://bydat.github.io/portfolio_new/`**
